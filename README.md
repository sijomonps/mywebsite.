#  Make Your First Website in 2 Hours using AI, Git & GitHub

This repository was created as part of a live workshop conducted for **BSc Computer Science students at Assumption College, Changanacherry**.

---

##  Workshop Title

**"Make Your First Website in 2 Hours using AI, Git & GitHub"**

---

##  About the Workshop

This beginner-friendly workshop was designed to help students build their first website within just 2 hours using modern tools and AI assistance.

The main objective was to show students how quickly they can start building and publishing projects using the right tools and guidance.

---

##  Technologies & Tools Used

- HTML  
- CSS  
- AI Tools (for generating code and ideas)  
- Git  
- GitHub  

---

##  What Students Learned

- How to create a simple website structure  
- How to use AI to generate and improve code  
- How to initialize a Git repository  
- How to commit changes using Git  
- How to push projects to GitHub  
- Basics of version control
